The flat card language
Hierarchy comes from type scale, alignment and spacing — never from stacked cards, borders on every block, or strong shadows. Top-level cards sit directly on the page ground: no group panel, no white sheet, no nested rounded box. --wash is a control surface (fields, hover rows, a small chart bed), never a second card level. Interaction is ink; --data-primary carries chart and composition emphasis, and a static metric never wears the action colour.

Badge · Progress · Separator
badge.tsx · progress.tsx · separator.tsx
nháp đang chạy quá hạn
0 300 tr
Progress has no solid track pill — it is hairline ticks, so the filled run reads as a measured stretch of scale rather than a block of colour. The geometry is a fixed pitch (2px tick every 6px), not a fixed tick count: a fixed count has to divide the container, so the gap grows with the column and the same control reads dense in a card but sparse in a wide panel. Holding the pitch keeps ink density constant at every width. Track and fill share one background anchored to the same left edge, so their ticks are always in phase and none slides as the value animates. Colour comes from currentColor — data-primary by default, since a goal bar shows data, not an action. Separator uses the divider token; Badge states its meaning in text, never colour alone.

Empty state & dependency notice
panel.tsx + sub-section.tsx — empty and missing-input states inside the top-level card.

Thêm nguồn tiền
An empty state is not a sub-card — it sits directly inside the top-level card. The placeholder sentence becomes a lucide icon: "Chưa có khoản nào" only restated the emptiness the blank area already showed, and a muted glyph reads as "nothing here yet" at a glance. Icons are lucide at stroke-width 1.75 to match the app, centred and given real vertical room — an empty area needs an anchor, not a stray mark in the corner. Every icon carries an aria-label, so the state is still spoken. What stays in words is what an icon cannot say: the action, and — for a dependency notice — which input is missing. The notice keeps its real answer (Chưa tính được) and never fakes a zero.

Inherit the tokens, no bespoke treatment
These carry no bespoke surface treatment — they take the tokens as they come: Dialog · Sheet · ResponsiveDialog · ConfirmDialog · Popover · DropdownMenu · Command · Select · Checkbox · Switch · Slider · Calendar · DatePicker · MonthPicker · Textarea · Label · Skeleton · Sonner · Table · DataTable · QRCode · QRScanner · Motion.
